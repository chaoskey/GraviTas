# N001 · Hawking 温度的三种推导与交叉检验

> 写于 2026-11-03 · 关联：[P01](../problems/P01-black-hole-information.md)
> 目标：不查任何资料，独立推出 `T_H = 1/(8πGM)`，并用三条独立路径互证。

---

## 0. 结论

```
T_H = ħ c³ / (8π G M k_B)
```

自然单位制（`G = c = ħ = k_B = 1`）：

```
T_H = 1/(8πM) ,    κ = 1/(4M) ,    T_H = κ/(2π)
```

熵：

```
S_BH = A/(4G) = 4πM²
```

---

## 1. 设定

Schwarzschild 度规（`G = c = 1`）：

```
ds² = −f(r) dt² + f(r)⁻¹ dr² + r² dΩ² ,    f(r) = 1 − 2M/r
```

视界在 `r_h = 2M`。表面重力定义为视界附近静止观测者的固有加速度（红移到无穷远）：

```
κ = (1/2) f'(r_h)
```

代入 `f'(r) = 2M/r²`，得

```
κ = M/(2M)² = 1/(4M)
```

---

## 2. 方法 A：欧氏周期法

### 2.1 延拓到欧氏号差

令 `t = −iτ`：

```
ds²_E = f dτ² + f⁻¹ dr² + r² dΩ²
```

### 2.2 视界附近展开

令 `r = 2M + ρ̃`，则

```
f(r) ≈ f'(2M) ρ̃ = ρ̃/(2M)
```

于是

```
ds²_E ≈ (ρ̃/2M) dτ² + (2M/ρ̃) dρ̃² + (2M)² dΩ²
```

### 2.3 换成固有径向坐标

令 `ρ² = 8M ρ̃`，即 `ρ̃ = ρ²/(8M)`，`dρ̃ = ρ dρ/(4M)`。代入：

```
(2M/ρ̃) dρ̃² = (2M · 8M/ρ²) · (ρ² dρ²)/(16M²) = dρ²
(ρ̃/2M) dτ² = (ρ²/16M²) dτ²
```

得到

```
ds²_E ≈ dρ² + ρ² (dτ/4M)² + (2M)² dΩ²
```

### 2.4 消去锥奇点

这是 `(ρ, θ)` 平面上的极坐标，其中 `θ = τ/(4M)`。
`ρ = 0` 处没有锥奇点的条件是 `θ` 的周期为 `2π`，即

```
τ ~ τ + 8πM
```

### 2.5 读温度

欧氏时间周期 `β = 1/T`，所以

```
β = 8πM   ⇒   T = 1/(8πM)
```

恢复量纲：

```
T_H = ħ c³/(8π G M k_B)
```

**关键点**：`β` 不是"坐标 `t` 的周期"这种约定，而是**几何要求**——
否则 `ρ=0` 处会出现一个真实的锥形奇点（曲率在那里是 δ 函数）。

---

## 3. 方法 B：表面重力 + Unruh

视界附近的度规近似为 Rindler 形式：

```
ds² ≈ −κ² x² dt² + dx² + (横向)
```

一个在视界外静止的观测者，其固有加速度为 `a = κ`。
Unruh 效应给出，加速观测者看到的真空温度为

```
T_U = a/(2π) = κ/(2π)
```

而无穷远观测者看到的温度因红移因子 `√(−g_tt)` 修正，恰好得到同一个 `κ/(2π)`。

```
T_H = κ/(2π) = 1/(8πM)
```

与方法 A 完全一致。

---

## 4. 方法 C：欧氏作用量与热力学

在 `β = 8πM` 时，欧氏 Schwarzschild 几何是一个光滑的"雪茄"。
其欧氏作用量（仅边界项贡献，因为 `R = 0`）为

```
I_E = βM/2 = 4πM²
```

配分函数 `Z = e^{−I_E}`，于是

```
S = βM − I_E = 8πM² − 4πM² = 4πM²
```

而 `A = 4π(2M)² = 16πM²`，所以

```
S = A/4
```

这与 Bekenstein–Hawking 公式一致——**热力学自洽性检验通过**。

---

## 5. 一致性检验（这一步比推导更重要）

| 检验 | 结果 |
|---|---|
| Smarr 公式 `M = 2TS` | `2 · (1/8πM) · 4πM² = M` ✓ |
| 第一定律 `dM = T dS` | `dS = 8πM dM`，`T dS = dM` ✓ |
| 量纲 | `T ~ ħc³/(GM k_B)`，是温度 ✓ |
| 经典极限 `M → ∞` | `T → 0`，黑洞变冷 ✓ |
| 与 Unruh 的连续性 | `κ → a`，`T → a/2π` ✓ |

---

## 6. 我一开始错在哪（留档）

1. **把 `κ` 当成"视界处的加速度"**。实际上无穷远观测者测到的加速度要乘红移因子，
   `κ` 的定义正是"红移到无穷远后的加速度"。
2. **用 `t` 的周期而不是 `τ` 的周期**。欧氏化之后，`t` 已经变成 `τ`，周期的几何意义完全不同。
3. **以为锥奇点只是坐标问题**。`ρ=0` 处的锥奇点对应曲率的 δ 函数，是**真实**的奇点，
   不是坐标假象。
4. **恢复量纲时漏掉 `ħ`**。经典黑洞没有温度，`T ∝ ħ` 是量子效应的标志。

---

## 7. 延伸

- 如果 `f(r)` 有多个视界（Kerr、dS），欧氏化会在每个视界处出现锥奇点，
  只有**一个** `β` 能同时消去所有锥奇点——这解释了为什么多视界时空的量子态是混合态。
- 对 dS：`T = H/(2π)`，`S = 3π/(GΛ)`（见 [P07](../problems/P07-cosmological-constant.md)）。
- 对偶视角：AdS/CFT 中，`T_H` 对应边界 CFT 的温度，Page 曲线从这里开始
  （见 [P01](../problems/P01-black-hole-information.md)）。
