## 1. Wick rotation：把振荡变成衰减

### 1.1 问题

闵可夫斯基空间的路径积分是

```
Z = ∫ Dφ  e^{iS[φ]}
```

`e^{iS}` 是相位，模长恒为 1，积分不绝对收敛。数学上它只是一个形式记号。

### 1.2 操作

令

```
t = −i τ        （τ 是实数，叫欧氏时间）
```

于是 `∂_t = i ∂_τ`，`dt = −i dτ`。对标量场

```
S = ∫ dt [ ½ (∂_t φ)² − V(φ) ]
  = ∫ (−i dτ) [ −½ (∂_τ φ)² − V(φ) ]
  = i ∫ dτ [ ½ (∂_τ φ)² + V(φ) ]
  ≡ i S_E
```

其中

```
S_E[φ] = ∫ dτ [ ½ (∂_τ φ)² + V(φ) ]
```

是**欧氏作用量**。于是

```
e^{iS} = e^{−S_E}
```

指数从虚变实，且 `S_E` 有下界（对正常势），积分变成衰减的高斯型——这时它才**存在**。

### 1.3 这不是技巧

三个理由：

- **定义**：欧氏路径积分是构造量子场论测度的标准方式（Osterwalder–Schrader 公理）；
- **计算**：它把量子涨落变成统计力学的配分函数，于是你可以借统计物理的全部工具；
- **结构**：它把"温度"翻译成"时间的周期"，这是本文后面一切的基础。

号差也变了：`(−,+,+,+) → (+,+,+,+)`。所以叫"欧氏"。

## 2. 核心：`Tr e^{−βH}` 是一条闭合路径

这一节是整个补丁的关键。**必须能自己重推。**

### 2.1 从振幅开始

量子力学里，传播子是

```
⟨q_f| e^{−βH} |q_i⟩ = ∫_{q(0)=q_i}^{q(β)=q_f} Dq  e^{−S_E[q]}
```

其中

```
S_E[q] = ∫_0^β dτ [ (m/2) q̇² + V(q) ]
```

为什么？把 `e^{−βH}` 切成 `N` 片，每片 `ε = β/N`：

```
e^{−βH} = ( e^{−εH} )^N
```

在每两片之间插入完备性 `∫ dq_k |q_k⟩⟨q_k| = 1`，得

```
⟨q_f|e^{−βH}|q_i⟩ = ∫ ∏_{k=1}^{N−1} dq_k  ∏_{k=0}^{N−1} ⟨q_{k+1}| e^{−εH} |q_k⟩
```

其中 `q_0 = q_i`，`q_N = q_f`。

### 2.2 单片矩阵元

```
⟨q'| e^{−εH} |q⟩ = ∫ dp/(2π)  e^{ip(q'−q)}  e^{−ε[p²/2m + V(q)]}
```

对 `p` 做高斯积分：

```
⟨q'| e^{−εH} |q⟩ = ( m / 2π ε )^{1/2}  exp[ − m(q'−q)²/(2ε) − ε V(q) ]
```

### 2.3 拼回去

把 `N` 个因子相乘。指数上是

```
− Σ_k [ m(q_{k+1}−q_k)²/(2ε) + ε V(q_k) ]
```

当 `ε → 0`，`(q_{k+1}−q_k)/ε → q̇`，`ε Σ_k → ∫_0^β dτ`，于是

```
Σ_k [ ... ]  ⟶  ∫_0^β dτ [ (m/2) q̇² + V(q) ] = S_E[q]
```

连同前面的 `∏ (m/2πε)^{1/2}`（它是测度的归一化因子），就得到 2.1 的路径积分。

### 2.4 取迹：闭合

现在算配分函数：

```
Z(β) = Tr e^{−βH} = ∫ dq  ⟨q| e^{−βH} |q⟩
```

注意：`Tr` 是**对角元之和**，不是 `⟨0|...|0⟩`。
把 2.1 代入，取 `q_i = q_f = q`，再对 `q` 积分：

```
Z(β) = ∮_{q(0)=q(β)} Dq  e^{−S_E[q]}
```

路径的起点和终点是同一个点——**一条闭合的环**。
这条环的"周长"（欧氏时间的总长）就是 `β`。

> **这就是全部的秘密**：配分函数不是"从某点出发走一段"，而是"绕一圈回来"。
> 所有"温度 = 周期的倒数"的结论，都从这里长出来。

### 2.5 两个容易混的点

| 容易错 | 正确 |
|---|---|
| `Z = ⟨0|e^{−βH}|0⟩` | `Z = Σ_n ⟨n|e^{−βH}|n⟩`，要对**所有**态求和 |
| 边界条件是 `q(0)=0, q(β)=0` | 边界条件是 `q(0) = q(β)`，**不固定**，还要对 `q(0)` 积分 |

## 3. 温度 = 环的周长倒数

统计力学里

```
Z(β) = Σ_n e^{−β E_n} ,    β = 1/(k_B T)
```

单位制取 `k_B = 1`，则 `β = 1/T`。

结合 §2.4：**欧氏时间是一个周长 `β` 的圆**，于是

```
T = 1/β ,    β = 欧氏时间圆的周长
```

换句话说：

> 温度不是"系统有多热"的度量，而是"虚时间方向被紧致化得多紧"的度量。

这句话现在可能只是顺口。等你在 Schwarzschild 上算出 `β = 8πM`，它会变得具体。

## 4. 两个检验

### 4.1 自由粒子在盒子里

```
⟨q|e^{−βH}|q'⟩ = ( m / 2πβ )^{1/2} exp[ − m(q−q')²/(2β) ]
```

取 `q = q'`，对 `q ∈ [0, L]` 积分：

```
Z = L ( m / 2πβ )^{1/2}
```

`Z ∝ 1/√β`。`β` 越小（越热），可及的态越多，`Z` 越大。这是第 3 节"紧致化"的图像。

### 4.2 谐振子

能级 `E_n = ω(n + ½)`：

```
Z = Σ_n e^{−βω(n+½)} = e^{−βω/2} / (1 − e^{−βω}) = 1 / ( 2 sinh(βω/2) )
```

两个极限：

- `βω ≫ 1`（低温）：`Z → e^{−βω/2}`，只剩基态；
- `βω ≪ 1`（高温）：`Z → 1/(βω)`，能级被"抹平"。

**用路径积分算同一个 `Z`**：作用量是 `∫ (m/2)(q̇² + ω²q²)`，圆上的本征值是
`(2πn/β)² + ω²`，行列式乘积需要对 `n` 做 zeta 正规化，且 `n = 0` 零模要单独处理，
最后同样给出 `1/(2 sinh(βω/2))`。

这条路技术细节多、和黑洞无关，**先跳过**。你只需要相信两件事：
能级求和给 `1/(2 sinh)`；路径积分给同一个数——这说明 §2 的等价不是空话。

## 5. 场论版本：Matsubara 频率

把 `τ` 紧致成周长 `β` 的圆后，场在 `S¹ × R³` 上。对 `τ` 做傅里叶展开：

```
φ(τ, x) = T Σ_n ∫ d³p/(2π)³  e^{i ω_n τ + i p·x}  φ_n(p)
```

周期条件 `φ(τ + β) = φ(τ)` 迫使频率离散：

```
ω_n = 2π n T        （玻色子）
```

于是"连续频率"变成"离散频率之和"——这正是有限温度场论与零温场论的全部差别。

费米子要反周期（`φ(τ+β) = −φ(τ)`），给出 `ω_n = (2n+1)πT`。这里不展开。

**记住一个图像**：有限温度 = 时间方向被卷成一个圆；`T` 越大，圆越细。

## 6. 弯曲时空：几何唯一决定温度

现在把 §2–§5 搬到弯曲时空。这一步是 Hawking 温度的来源。

### 6.1 定理（陈述，不证）

若一个欧氏度规在某个"视界"处要**光滑**（没有锥奇点），那么时间方向的周期被几何
唯一确定。

近视界处，任何有 Killing 视界的度规都可以写成 Rindler 形式：

```
ds² ≈ dρ² + κ² ρ² dτ² + (横向)
```

其中 `κ` 是表面重力。这是平面极坐标 `dρ² + ρ² dθ²`，只要令 `θ = κ τ`。
平面在原点光滑的条件是 `θ` 的周期为 `2π`，所以

```
τ ~ τ + 2π/κ   ⇒   β = 2π/κ   ⇒   T = κ/(2π)
```

### 6.2 这条定理为什么"是"物理

因为它把温度变成了**几何的自洽性条件**：

> 时空不能在视界处长出一个锥尖。要不长锥尖，虚时间就必须以特定周期卷起来。
> 那个周期就是 `1/T`。

于是"黑洞有温度"不再是一个需要额外输入的事实，而是"视界附近的欧氏几何必须光滑"的推论。

### 6.3 你的任务

§6.1 说"任何有 Killing 视界的度规都能写成 Rindler 形式"。**这句话在 Schwarzschild 上
具体长什么样**，就是 [N001](N001-hawking-temperature.md) 的阶梯 C：

- 取 `f = 1 − 2M/r`，在 `r = 2M` 附近展开；
- 换径向坐标，让度规写成 `dρ² + ρ²(...)²`；
- 读出 `( ... )` 里的系数，令它对应 `2π` 周期。

这一步**我不会替你算**。
