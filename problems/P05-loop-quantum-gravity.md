# P05 · 圈量子引力与离散时空

> **一句话**：时空本身是否由离散的量子几何构成——面积与体积算符有分立谱，
> 空间是自旋网络的一次"激发"？

## 1. 问题是什么

LQG 走的是**正则量子化**的路：不引入新对象（弦、额外维），而是直接把 Einstein 方程
按 ADM 分解后量子化，只是换了一组更好的变量——Ashtekar 变量。

结果是：几何算符（面积、体积）作用在自旋网络态上，给出**离散谱**。
空间在普朗克尺度上不是连续的，而是"编织"出来的。

于是核心问题变成：
- 这种离散结构能否在低能下**光滑化成**经典时空？
- 动力学（Hamiltonian 约束）能否自洽地解出来？

## 2. 为什么它是入口

它给出了对"量子引力"最字面的回答：**量子化时空本身**。
而且它有三个别的方案没有的品质：

1. **背景独立**：不预设度规，理论自己决定几何；
2. **非微扰**：不是对 `G` 做展开，而是精确量子化约束；
3. **可计算**：面积谱、黑洞熵、宇宙学反弹都有明确结果。

它的困难同样典型：**如何证明低能极限是广义相对论**——这个问题至今没有令人满意的答案。

## 4. 当代状态（2025）

**已经做到的**：
- 面积/体积谱的严格计算（离散，最小面积隙）；
- 黑洞熵 `S ∝ A` 的微观计数，且能固定 Immirzi 参数到 `γ ≈ 0.24`（不同计数方案结果略有差异）；
- LQC 给出无奇点的反弹，且反弹后的扰动谱可计算。

**没有做到的**：
- **完整动力学**：Hamiltonian 约束的解空间仍不清楚，物理内积未定；
- **半经典极限**：从自旋网络到光滑度规的推导只有零散结果，没有系统性证明；
- **物质耦合**：标准模型如何接入，仍未解决；
- **可检验预言**：几乎没有。离散性在普朗克尺度，直接观测无望。

**一句话判断**：作为"量子几何"的数学框架它很成功，作为"我们的宇宙的量子引力理论"它还差一步——那一步恰好是最难的。

## 5. 核心概念与公式

**Ashtekar 变量**：`(A_a^i, E^a_i)`，其中 `A` 是 `SU(2)` 联络，`E` 是共轭的密度化标架。

**面积谱**（自旋网络的一条边，自旋 `j`）

```
A = 8π γ ℓ_P² √( j(j+1) )
```

`γ` 是 Barbero–Immirzi 参数。注意：**面积是离散的**，最小间隙在 `j = 1/2`。

**体积谱**：由顶点处三个边的自旋纠缠给出，同样是离散的。

**黑洞熵计数**

```
S = (γ₀/γ) · A/(4G) ,   γ₀ ≈ 0.24
```

要求 `S = A/4G` 就把 `γ` 固定下来——这是 LQG 唯一"可被数据选择"的参数。

**LQC 反弹**

```
H² = (8πG/3) ρ (1 − ρ/ρ_c)
```

当 `ρ → ρ_c ~ ρ_Planck` 时 `H → 0`，宇宙反弹而不是撞上奇点。

## 7. 进入路径

**第 1 步（2 周）· ADM + Ashtekar 变量**
先确保你懂 ADM 约束，再看 Ashtekar 变量如何把约束变成多项式形式。

**第 2 步（3 周）· 面积算符**
亲手算一个自旋 `j` 边的面积本征值。这一步很短，但能让你"摸到"离散性。

**第 3 步（2 周）· 熵计数**
读 Rovelli 1996 或 ABK 1998。重点不是技术，而是：为什么计数会给出 `S ∝ A` 而不是别的？
