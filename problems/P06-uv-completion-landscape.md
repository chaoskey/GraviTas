# P06 · 紫外完备的光谱：竞争方案与判据

> **一句话**：除了弦论与 LQG，还有哪些自洽的量子引力方案？我们该用什么标准判断它们？

## 1. 问题是什么

"量子引力"不是一场只有一个擂主的比赛。至少存在六七种**结构上不同**的方案，
它们对"紫外问题"给出了根本不同的答案：

| 方案 | 对"紫外"的回答 |
|---|---|
| 弦论 | 基本对象延展化，天然截断 |
| 圈量子引力 | 几何本身离散化，面积有最小间隙 |
| 渐近安全 | 引力在紫外存在非平凡固定点，$G \to 0$ |
| 因果动力学三角剖分 | 时空由单纯形拼接，普朗克尺度离散 |
| 因果集 | 时空是偏序集，离散性 + 因果序 |
| 群场论 / 张量模型 | 自旋泡沫的二次量子化，凝聚 → 时空 |
| 非交换几何 | 坐标算符不对易，几何在普朗克尺度"模糊" |
| 类比引力 | 不是 QG 理论，但提供可实验的"视界物理" |

## 2. 为什么它是入口

因为**判断力**比知识更重要。你不可能把每个方案都学到底，但你可以学会：
一个方案在什么意义上"解决了"紫外问题，又付出了什么代价。

这也是防止被"某派叙事"带走的方法：每个方案都有它回避的问题。

## 3. 各方案速写

### 3.1 渐近安全（Asymptotic Safety）

Wilson 重整化群的思路：引力也许不是"不可重整"，而是有一个**非平凡 UV 固定点**。
在固定点附近，$G(k) \sim g_* / k^2$，引力耦合在紫外变弱，发散被吸收。

- 证据：函数重整化群（FRG）在截断近似下反复找到固定点；
- 弱点：截断依赖、无法控制高阶算子、固定点的物理意义仍有争议；
- 关键文献：Weinberg 1979（提出）、Reuter 1998（FRG 计算）、Eichhorn 综述。

### 3.2 因果动力学三角剖分（CDT）

用单纯形拼出时空，对拼接方式做路径积分求和。
四维 CDT 的相图里出现了一个**延展的、类似 de Sitter 的相**——这是它最著名的结果。

- 优点：纯数值，非微扰，直接给出宏观几何；
- 弱点：没有已知的连续极限解析描述，与物质耦合困难。

### 3.3 因果集（Causal Sets）

假设时空在普朗克尺度是**离散的偏序集**：元素是事件，序关系是因果。
"序 + 数 = 几何"（Rideout–Sorkin）：因果序加上元素计数，足以恢复度规与体积。

- 著名"预言"：宇宙学常数 $\Lambda \sim 1/\sqrt{V}$，量级恰好接近观测值（Sorkin 1990s）；
- 弱点：动力学（如何"生长"出一个因果集）仍是开放问题。

### 3.4 群场论 / 张量模型（GFT）

把自旋泡沫"二次量子化"：场算符产生/湮灭空间的基本单元，时空是凝聚态。
LQG 的宇宙学版本可以从中导出。

### 3.5 非交换几何

Connes 的谱三元组：几何由代数 $(A, H, D)$ 决定，坐标不再对易。
谱作用量可以同时给出 Einstein–Hilbert 项与标准模型拉氏量——这是它最吸引人的地方。

### 3.6 涌现引力 / 熵引力

Jacobson (1995)：Einstein 方程是 $\delta Q = T\,dS$ 的状态方程。
Verlinde (2010)：引力是熵力。Padmanabhan：引力是"宇宙的微观自由度对宏观几何的响应"。

- 优点：把引力与热力学/信息联系起来，与 P03 同源；
- 弱点：多数推导是"逆向工程"，缺少独立的微观模型。

### 3.7 扭量理论 / 形状动力学 / 其他

Penrose 的扭量：时空点不是基本的，光线（扭量）才是。
Barbour 的形状动力学：用"形状"替代绝对时间。这些方案影响力较小，但提供概念对照。

## 4. 判据（用这张表打分）

| 判据 | 问题 |
|---|---|
| **UV 机制** | 它到底靠什么消除发散？截断、固定点、还是离散？ |
| **背景独立** | 是否预设了度规/拓扑？ |
| **低能极限** | 能否**推导出**（而非假设）Einstein 方程？ |
| **黑洞熵** | 能否给出 $S = \frac{A}{4G}$？能否给出 Page 曲线？ |
| **幺正性** | 演化是否幺正？信息是否守恒？ |
| **可计算性** | 有没有能算的具体模型？ |
| **可检验性** | 有没有任何观测/实验能排除它？ |
| **概念代价** | 它要求你放弃什么（洛伦兹不变性、时空连续性、局域性……）？ |

## 5. 对比表（主观评分，1–5）

| 方案 | UV 机制 | 背景独立 | 低能极限 | 黑洞熵 | 可计算 | 可检验 | 概念代价 |
|---|---|---|---|---|---|---|---|
| 弦论 | 5 | 3 | 4 | 5 | 4 | 1 | 高（额外维、超对称） |

## 7. 进入路径

**第 1 步（1 周）· 只读对比表**
不读任何论文，先把第 5 节表格的每一格，用你自己的话解释一遍。解释不了的格子，就是你的下一步。

**第 2 步（2 周）· 挑一个"你最不信"的方案**
通常建议挑渐近安全——它最像"正常"的量子场论，也最容易让你看到"固定点"到底意味着什么。

**第 3 步（2 周）· 写一页对比**
选两个方案，就**同一个问题**（比如黑洞熵）写出它们各自的做法。这一页纸比读十篇综述有用。

## 8. 自检问题

1. "不可重整"与"有 UV 固定点"是否矛盾？为什么？
2. CDT 的 de Sitter 相为什么重要？它算不算"推导出了"广义相对论？
3. 因果集的 $\Lambda \sim 1/\sqrt{V}$ 是预言还是巧合？怎么区分？
4. 一个理论如果"背景独立"，它如何定义散射振幅？
5. 如果所有方案都得不出可检验预言，量子引力还算物理学吗？
