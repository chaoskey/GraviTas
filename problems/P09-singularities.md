# P09 · 奇点与黑洞内部

> **一句话**：奇点真的是时空的终点吗？事件视界之内发生了什么？
> 经典理论在那里失效，量子引力必须给出替代品。

## 1. 问题是什么

奇点定理说：在很一般的条件下，时空必然测地不完备。但"测地不完备"只是一个数学事实，
它没有告诉我们**物理上**发生了什么。

三种可能：
1. 时空在那里真的终结（奇点作为边界）；
2. 量子效应抹平曲率，形成一个高曲率但有限的区域（"普朗克星"、正则黑洞）；
3. 时空"反弹"，内部连接到一个白洞或另一个宇宙（"黑洞-白洞跃迁"）。

这三种可能对应**完全不同**的物理，而目前的观测无法区分。

## 2. 为什么它是入口

因为它是**离我们最近的量子引力**。黑洞并合、引力波铃宕、EHT 阴影，都在视界附近发生。
如果量子引力有任何"低能残留"，最可能在这里。

同时它连接了 P01：黑洞内部的结构，决定了信息能否、以及如何从视界内"出来"。

## 4. 当代状态（2025）

**经典层面**：
- **弱宇宙监督**（奇点不裸露）在球对称情形下成立，在一般情形下**未证明**；
- **强宇宙监督**（Cauchy 视界稳定）在渐近 dS 时空中被证明**失效**（微扰下 Cauchy 视界仍可延拓）；
- 质量暴胀说明内视界附近曲率发散，经典描述崩溃得更早。

**量子层面**：
- 所有"消解奇点"的方案都是**模型**，不是从第一原理推出的；
- 没有方案给出可观测的、唯一的预言；
- 引力波回声（echoes）是最有希望的观测窗口，但目前的信号不显著。

## 5. 核心概念与公式

**Kretschmann 标量**（判断曲率是否真发散）

```
K = R_{μνρσ} R^{μνρσ} ~ M²/r⁶   （Schwarzschild）
```

**质量暴胀**：内视界附近， blueshift 使能量密度按 `e^{κ t}` 增长，
曲率在有限仿射参数内发散。

**Hayward 正则黑洞**

```
f(r) = 1 − 2 G M r²/(r³ + 2 G M ℓ²)
```

`ℓ` 是普朗克尺度截断。`r → 0` 时 `f → 1`，曲率有限——奇点被"挖掉"。
代价：需要引入一个**非引力**的截断尺度 `ℓ`，理论上并不自洽。

**普朗克星**：当黑洞质量降到 `M ~ M_P`，视界内的物质处于"普朗克密度"，
量子引力效应使其反弹，随后以白洞形式爆发（时间尺度 ~ `M²/M_P²` 秒）。

## 7. 进入路径

**第 1 步（2 周）· 奇点定理的证明结构**
只需掌握：能量条件 → 测地线汇聚 → 共轭点 → 不完备。不要求所有技术细节。

**第 2 步（2 周）· 内视界与质量暴胀**
读 Poisson–Israel 的图与结论。目标：说清为什么内视界不稳定。

**第 3 步（3 周）· 正则黑洞的代价**
对比 Hayward、Bardeen、Planck star 三种方案：它们各自引入了什么、放弃了什么。
