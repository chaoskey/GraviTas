# P01 · 黑洞信息悖论

> **一句话**：黑洞蒸发殆尽之后，最初落入其中的量子信息去了哪里？
> 如果它回来了，是怎么从"完全热的"霍金辐射里回来的？

## 1. 问题是什么

把一个纯态扔进黑洞。黑洞通过霍金辐射缓慢蒸发，最终消失。
半经典计算（弯曲时空量子场论 + 固定背景）给出的辐射谱**精确地是热的**：

- 热谱意味着辐射态是混合态，其 von Neumann 熵随蒸发单调上升；
- 黑洞消失后，只剩下热辐射，纯态 → 混合态；
- 这与量子力学的幺正演化直接冲突。

如果坚持幺正性，那么辐射**必须**携带信息。但这要求辐射之间存在精细的关联，
而半经典计算明确给出这些关联为零。矛盾就在这里：**不是算错了，而是框架不够用**。

## 2. 为什么它是量子引力的入口

它同时踩住了三个支柱，缺一不可：

| 支柱 | 在悖论中的角色 |
|---|---|
| 广义相对论 | 视界、因果结构、"内部"的存在 |
| 量子场论 | 真空的定义、粒子概念、热谱 |
| 量子信息 | 纯态/混合态、纠缠熵、幺正性 |

任何一个自洽的量子引力理论，都必须在这个句子里同时成立：
**"纯态演化 + 视界 + 热辐射"**。这就是它比其他问题更硬的原因。

## 4. 当代状态（2025）

**已经取得的**：在 AdS/CFT 与低维引力（JT gravity）中，引力路径积分对几何求和后，
确实给出 Page 曲线；岛屿公式 `S = min ext [A/4G + S_bulk]` 可以从复制虫洞推导出来。
这被认为是"信息确实守恒"的强证据。

**还没有的**：
- 一个不依赖 AdS 边界的、非微扰的量子引力定义；
- 从 CFT 数据出发**构造**黑洞内部（而不只是证明它存在）；
- 对"状态依赖"与"系综平均"哪个才是正确的解释，没有共识；
- 宇宙学视界（dS）中的对应版本仍不清楚。

**一句话判断**：悖论在"技术层面"已基本被解决，在"概念层面"没有。

## 5. 核心概念与公式

**Bekenstein–Hawking 熵**

```
S_BH = A / (4 G ħ)
```

**Hawking 温度**

```
T_H = ħ c³ / (8 π G M k_B)     （Schwarzschild）
```

**Page 曲线**：若演化幺正，辐射熵满足
`S_rad(t)` 先随蒸发上升，在 Page time（约蒸发一半时）达到最大，然后对称下降回 0。

**岛屿公式**（量子 extremal surface）

```
S(R) = min_{I} ext_{∂I} [ A(∂I)/(4G) + S_bulk(I ∪ R) ]
```

其中 `R` 是辐射区域，`I` 是"岛屿"区域（黑洞内部的一部分），`A` 是岛的边界面积。
早期没有岛（`I = ∅`），熵上升；Page time 之后岛出现，面积项主导，熵下降。

## 7. 进入路径

**第 1 步（2 周）· 把 Hawking 计算做一遍**
用欧氏周期法算 `T_H`，再用 Bogoliubov 系数法算一遍，对照。
参考：[N001](../notes/N001-hawking-temperature.md)。

**第 2 步（2 周）· 理解 Page 曲线为什么是幺正性的判据**
不读技术细节，只回答：为什么"熵先升后降"就等价于"信息回来了"？
动手画一条 Page 曲线，标出 Page time。

**第 3 步（4 周）· 读 AMPS 与岛屿公式**
先读 AMPS 的引言（两页），写出三难；再读 2021 综述的第 1–3 节。
目标：能用自己的话解释 `min ext` 里为什么有 `min`。

5. 如果信息守恒，为什么我们**看不到**它？"重构"难在哪里？
